A one-line excuse from a robot vacuum for missing a spot, in the vacuum's own deadpan voice: it bumped into the spot six times, classified the dust as load-bearing, and respectfully routed around it. The program writes the line to /output/entry.txt.

## Run it

```sh
python3 main.py
```
